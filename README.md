# Touch Invaders

A mobile-friendly invader game built as a small GitHub Pages app.

## Play

After GitHub Pages is enabled, open:

https://ny1515.github.io/touch-invaders/

## Mobile install

- Android Chrome: open the URL, then choose **Add to Home screen**.
- iPhone Safari: open the URL, tap Share, then choose **Add to Home Screen**.

## Controls

- Touch or drag the play area to move.
- Tap the fire button to shoot.
- Desktop: arrow keys or A/D to move, Space to shoot.

## Security and Privacy

- This game is static and has no API keys, passwords, database connections, admin screens, or data-changing features.
- Do not publish company-internal information, personal information, or secrets in this repository.
- If admin screens or data-changing features are added later, authentication and authorization must be implemented before publishing.
